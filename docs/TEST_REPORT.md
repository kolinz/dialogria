## 自動試験の範囲

- 画像の実形式検証、SVG偽装拒否、WebP変換・EXIF除去、画像の第三者取得拒否。
- .env相当の環境変数→管理画面上書き→明示停止→環境変数への復帰。設定取得APIに秘密値が出ない。
- サーバー側ページング、ログの期間／レベル絞込。
- 推奨OpenAIモデルの受信イベントfixtureからPCM/WAV変換、文字起こし不一致の拒否。実OpenAI WebSocket接続試験とは区別する。
- 未認証API、CSRF欠落、管理者認可、秘密値暗号化、パスワード非公開、ローカル接続先許可リスト。
- PUBLIC/PRIVATE/INVITE_ONLYルーム、非参加者参照拒否、招待受諾、公開参加、参加者の編集拒否。
- A/B/A確定投稿の順序、クライアント冪等キーによる重複排除、投稿後の種別変更禁止。
- GeminiなしでMP4有効化／生成を拒否。Ollama/VOICEVOXのテスト用HTTPエンジンで文章と音声の接続検証。
- 拡張候補だけでは投稿を増やさない。3投稿スナップショット作成後の4投稿目を旧教材に混入させない。
- 3投稿のMarkdownを1ファイル生成し、AI拡張の原文を保持。無権限ダウンロード拒否。
- 未試聴のBを含む全3投稿のMP3を実生成。FFprobeでMP3形式と約1.5秒の音声長を検証。
- 音声OFFで既存MP3の取得を拒否。匿名画像選択と3区間の連続タイムラインを検証。
- 実Socket.IOの2クライアントで確定投稿を同期。退出後の購読・履歴取得を拒否。
- ローカルアバターレンダラーのMP4を16:9/9:16・字幕ON/OFFで実生成。H.264＋AAC・寸法・尺をFFprobeで確認。
- 講師の固定設定版、公開情報の秘匿、無効化後の新規選択拒否。強制削除理由・監査・削除後拒否。

MP4レンダラー試験ではGemini接続条件を**テスト用に注入**し、ローカルレンダラーを直接検証する。製品APIのGemini未接続時にMP4を許可するものではない。テスト後に検証状態とキーを取り除き、既存MP4の取得も拒否されることを確認する。
