# Dialogria

AI対話学習・音声教材生成プラットフォーム

## 起動

Node.js **24 LTS**、npmを使用します。Dockerは不要です。

```sh
npm ci
cp env.example .env
npm run db:migrate
# .env の INITIAL_ADMIN_EMAIL / INITIAL_ADMIN_PASSWORD を設定してから起動
npm run dev
```

Web: http://127.0.0.1:5173 / API: http://127.0.0.1:3001/api/health 。`localhost`と`127.0.0.1`を混在させず、環境変数のオリジンに統一してください。

`.env`の`INITIAL_ADMIN_EMAIL`と`INITIAL_ADMIN_PASSWORD`（12〜128文字）を設定すると、初回のAPI起動時に管理者を作成します。表示名は`INITIAL_ADMIN_DISPLAY_NAME`で設定できます。両方未設定なら作成しません。一部だけの設定や既存ユーザーとのメール重複は拒否し、既存ユーザーの昇格・パスワード上書きは行いません。

初回作成の記録はDBに保存し、その後`.env`を変更したり再起動したりしても、既存の管理者やパスワードを上書きしません。作成後は「管理者アカウント」でメール・表示名・パスワードを変更できます。メール／パスワード変更後は全端末で再ログインします。`.env`の初期パスワードは作成後に削除しても動作します。

代替の`npm run admin:create`はメール、表示名、パスワードを対話入力します。既存ユーザーを無断昇格せず、新しい管理者だけを作ります。パスワードは12文字以上。既定パスワードや本番サンプルデータはありません。通常ユーザーは登録画面から作成します。

```sh
npm run typecheck
npm test
npm run build
npm run test:start
npm start
```

`dev`はViteとAPIを同時起動します。`build`はAPIとWebをビルドし、`start`はビルド済みExpressサーバーからWebも配信します。本番は `NODE_ENV=production`、HTTPS終端、32文字以上の `SESSION_SECRET` と `SETTINGS_ENCRYPTION_KEY` が必須です。同一オリジン配信では `WEB_ORIGIN` を実URLへ変更します。`start` 前に必ず再ビルドしてください。

## 最初の接続設定

1. 管理者でログインし、**AI・TTS設定**を開きます。
2. Gemini／OpenAIのキーと利用モデル名を`.env`に定義するか、管理画面で登録します。優先順位は管理画面の上書き → プロセスの環境変数 → `.env`です。保存済みキーを画面へ返しません。`.env`変更後はAPIサーバーを再起動してください。画面には設定元を表示し、「環境変数の設定に戻す」で管理画面の上書きを解除できます。キーの明示削除は環境変数の値も利用停止にします。
3. モデル・音声を取得し、文章・TTSそれぞれの**接続テスト**を実行します。
4. システム設定で必要な出力機能をONにします。
5. AI講師を登録し、有効化します。文章と音声の接続検証後に有効化できます。未接続でも無効状態の下書きとして講師を保存できます。

動画モデル初期値は `gemini-omni-1.1-flash`。動画接続テストは実際に短い動画を1本生成するため課金確認があります。動画は管理者ON・Gemini動画検証・TTS検証・ルーム権限・必要な同意をすべて満たす場合だけ利用できます。ローカルFFmpeg方式も同じ条件です。MP4生成／再試行／取得時はGeminiのモデルアクセス権も再確認します。

接続検証は24時間で期限切れになり、設定変更時は無効化されます。設定と認証情報の指紋も照合するため、`.env`のキー変更後に古い検証結果は流用しません。無効化した形式は保存済みファイルの取得も拒否します。新規状態はテキストON、音声OFF、動画OFFです。APIキー未設定でも登録・プロフィール・学生同士のチャット・Markdown書き出しは動作します。

## ローカルAIとVOICEVOX

Ollama、LM Studio、VOICEVOX ENGINEは別途起動します。`LOCAL_PROVIDER_ORIGINS`に許可したURLだけにサーバーから接続できます。URLのパス、認証情報、リダイレクトは拒否します。ブラウザからエンジンへ直接接続しません。

- Ollama: `/api/tags`、`/api/chat`
- LM Studio: `/v1/models`、`/v1/chat/completions`
- VOICEVOX: `/speakers`、`/audio_query`、`/synthesis`

VOICEVOXの話者IDは実際の話者一覧から選んでください。音声・キャラクターごとの利用規約とクレジット条件を運用者が確認します。Geminiなしでもローカル文章生成＋VOICEVOXでAI対話、個別発話、MP3、Markdownを利用できます。MP4は利用できません。

## 推奨モデル

2026-10-28の公式資料に基づき、文章は`gemini-3.8-flash`、OpenAI音声は`gpt-realtime-2.1-mini`（marin）、動画は`gemini-omni-1.1-flash`を初期値としています。実際の利用権限は接続テストで確認します。OpenAIの新しい音声モデルはサーバー間Realtime APIを使います。従来のAudio Speech対応モデルも選択可能です。設計変更の理由と公式リンクは`docs/ARCHITECTURE_DECISIONS.md`を参照してください。

## メディア生成

FFmpeg／FFprobeはnpm依存のホスト用バイナリを使用します。`FFMPEG_PATH`、`FFPROBE_PATH`で運用者のバイナリへ置き換えられます。日本語字幕には対応フォントが必要です。macOSの初期候補を `.env.example` に記載しています。LinuxではNoto Sans CJK等のライセンス確認済みフォントをインストールし、`SUBTITLE_FONT`にパスを設定してください。Appleフォントを他OSへ転載しないでください。

MP3とMP4は全確定発話を順番に各1回収録します。未試聴の投稿も含まれ、プレビュー回数では重複しません。Markdownと同じスナップショットを使います。TTS設定を変更した場合、旧スナップショットの新規音声生成は拒否し、新スナップショットを要求します。長いコードは音声で「コード例があります」、URLは「リンク」と読み、原文は変更しません。

MP4はH.264＋AAC、16:9または9:16。日本語字幕は発話ごとに同期し、長文は分割します。生成AI映像の音声は使いません。アバターは許諾のある画像のみ使い、未許諾はイニシャル表示にします。画像利用許諾の撤回後は該当MP4の再取得を拒否します。過去に利用者が保存したコピーは回収できません。

## データと運用

- DB: `data/dialogria.sqlite`、非公開ファイル: `storage/`。静的配信領域から分離され、Git対象外です。
- ローカル開発では暗号化鍵を `storage/.encryption` に生成します。DBと一緒に安全にバックアップしてください。鍵を失うと保存済みAPIキーを復号できません。
- ルーム削除は論理削除。参加権限・生成済み教材へのアクセスを停止します。管理者の強制削除は理由と監査ログが必須です。
- 永続ジョブは単一サーバー・同時処理1件。中断ジョブは再起動時に失敗へ移し、重複課金を避けるため自動再実行しません。再試行は最大3回。外部動画は追加課金の確認を要求します。
- 保存期限が切れた教材は取得できません。物理的な容量回収は `npm run storage:cleanup` を定期的に運用実行してください。
- DB変更前は停止してバックアップし、`db:migrate` を実行します。破壊的なdown migrationは提供せず、復元はバックアップから行います。
- 外部AIへ対話を送る場合はルーム設定と全参加者の同意が必要です。画像は外部生成APIへ送らず、映像生成には文章のシーン指示のみ送ります。

## OpenAI文章生成とユーザー管理

PDFはルームの「PDFをダウンロード」から書き出せます。固定済み会話の全文を、発言者アイコン・ルーム背景・吹き出し付きで保存します。背景画像やアバターがない場合も標準背景と代替アイコンで表示できます。画像はサーバー内の保存済み素材だけを使い、外部画像は取得しません。過去のスナップショットに保存されていないアバターは代替アイコンになる場合があります。

管理画面「システム設定」→「PDF出力設定」で、本文・コード用フォント、本文サイズ（8〜18pt）、用紙（A4 / Letter）を設定できます。未保存時は `.env` の `PDF_FONT=IPAexGothic`、`PDF_CODE_FONT=IPAexGothic`、`PDF_FONT_SIZE=11`、`PDF_PAGE_SIZE=A4` を使います。フォント値は `IPAexGothic` または `IPAexMincho`。保存値は再起動後も優先し、「環境変数の設定に戻す」で解除できます。環境変数の変更には再起動が必要です。プレビューは保存前の入力値でPDFをダウンロードします。PDFとMarkdownの利用可否は「テキスト教材」で制御します。生成ジョブは受付時のフォント設定を保持し、設定変更後の出力は別ジョブになります。

日本語フォントは `assets/fonts/IPAexfont00401/` に公式配布ファイルを無改変で同梱しています。IPAexフォントはアプリのライセンスとは別に、同梱の `IPA_Font_License_Agreement_v1.0.txt` に従います。配布元：https://moji.or.jp/ipafont/ipaex00401/ 。表示確認用のサンプルは `npx tsx scripts/verify-pdf.ts` で `output/pdf/dialogria-sample.pdf` に生成できます。

AI講師の発話ボタンの読み上げ上限は `.env` の `AI_LECTURER_SPEECH_MAX_CHARS=200` が標準値です（1〜4,000文字）。ルーム作成・編集画面の「AI講師の発話文字数上限」でルームごとに変更できます。Markdownを読み上げ用に整えた後、Unicodeコードポイント単位で先頭から上限までを音声化します。回答本文・参加者の発話・教材書き出しは全文を保持します。既存ルームはマイグレーション時の標準値を保存し、以降の環境変数変更では保存済み設定を上書きしません。

AI文章生成にGemini / OpenAI / Ollama / LM Studioを選べます。OpenAIは公式Responses APIを使用し、AI講師回答・文章拡張・シーン指示を生成します。OpenAI文章モデルは`OPENAI_TEXT_MODEL`、初期選択は`DEFAULT_TEXT_PROVIDER=OPENAI`で設定できます。モデル名が未設定なら管理画面で候補を取得し、選択・保存・接続テストを実行してください。OpenAIのキーはTTSと共通ですが、文章とTTSのモデル・接続検証は独立です。利用権限とResponses API対応は接続テストで判断します。外部送信はGeminiと同様にルームの許可と参加者全員の同意が必要です。

「ユーザー管理」→「ユーザーを作成」で、表示名・メール・自己紹介・初期パスワード・権限・利用状態を設定します。一覧の「編集」ではこれらの情報を変更し、必要な場合だけ新しいパスワードを設定できます。登録・編集には操作中の管理者のパスワードで再認証します。メール／パスワード／権限／利用状態を変更したユーザーの旧セッションを失効させます。自分自身の管理者権限停止と最後の有効な管理者の停止は拒否します。
